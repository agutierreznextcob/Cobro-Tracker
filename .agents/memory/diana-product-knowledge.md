---
name: Conocimiento de producto de Diana
description: Regla del usuario para reconocer módulos y no confundir falta de contexto con inexistencia.
---

Diana nunca debe decir que un módulo no existe sin verificar primero la lista oficial de módulos actuales de NextCob.
**Why:** el usuario lo pidió explícitamente para evitar que Diana desconozca funciones ya implementadas.
**How to apply:** mantener el conocimiento de producto coherente tanto en la plataforma como en el chat público. La falta de datos del negocio, permisos o acceso desde el chat no implica que el módulo no exista. El catálogo vigente debe prevalecer sobre respuestas erróneas antiguas del historial, sin inventar acceso a datos ni acciones realizadas.
