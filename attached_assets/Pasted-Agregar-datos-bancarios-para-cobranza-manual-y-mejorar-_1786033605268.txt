Agregar datos bancarios para cobranza manual 
y mejorar el flujo de pago por transferencia:

1. DATOS BANCARIOS EN EL PERFIL:
En la sección "Mi Perfil" agregar nuevo acordeón:

━━━━━━━━━━━━━━━━━━━━━━━━━━
🏦 Datos bancarios para transferencias  ▶
━━━━━━━━━━━━━━━━━━━━━━━━━━

Con los siguientes campos:
- Banco (selector: Banco de Chile, BCI, 
  Santander, Scotiabank, Itaú, BancoEstado, 
  Falabella, Ripley, Security, BICE, Otro)
- Tipo de cuenta (selector: Cuenta Corriente, 
  Cuenta Vista, Cuenta de Ahorro, Cuenta RUT)
- Número de cuenta
- Nombre del titular
- RUT del titular
- Email para recibir comprobantes (puede ser 
  distinto al email de la cuenta)

Estos datos se guardan encriptados y solo 
se usan para incluirlos en los mensajes 
de cobranza manual.

2. INCLUIR DATOS BANCARIOS EN MENSAJES:
Cuando se envía un recordatorio o cobro manual 
por email o WhatsApp, si el método de pago 
es "Manual/Transferencia" o si el cobro no 
tiene link de pago de Flow/MercadoPago, 
incluir automáticamente los datos bancarios 
del usuario en el mensaje:

TEMPLATE EMAIL:
"Hola [nombre cliente],

Te informamos que tienes un cobro pendiente:

Concepto: [descripción]
Monto: $[monto] [+ IVA si corresponde]
Vencimiento: [fecha]

Para realizar el pago por transferencia:
━━━━━━━━━━━━━━━━━━
Banco: [banco]
Tipo de cuenta: [tipo]
N° de cuenta: [número]
Titular: [nombre titular]
RUT: [RUT titular]
Email para comprobante: [email comprobante]
━━━━━━━━━━━━━━━━━━

Una vez realizada la transferencia, 
responde este correo adjuntando el 
comprobante de pago.

[Nombre del ejecutivo]
[Empresa]
via NextCob"

TEMPLATE WHATSAPP:
"Hola [nombre], tienes un cobro pendiente:
📋 Concepto: [descripción]
💰 Monto: $[monto]
📅 Vence: [fecha]

Datos para transferir:
🏦 [banco] | [tipo cuenta]
📝 N° [número cuenta]
👤 [nombre titular] | RUT [RUT]
📧 Comprobante a: [email]

Responde con tu comprobante ✅"

3. FLUJO DE CONFIRMACIÓN DE PAGO:
Cuando el cliente responde el email con 
el comprobante adjunto, el ejecutivo 
responsable del cobro recibe una 
notificación en la plataforma:

- Badge de notificación en el menú
- Alerta: "El cliente [nombre] envió un 
  comprobante para el cobro [concepto]"
- Botón directo: "Ver comprobante y 
  confirmar pago"
- Al confirmar, el cobro se marca como 
  "Pagado" automáticamente con la fecha 
  de confirmación

4. VALIDACIÓN:
Si el usuario no tiene datos bancarios 
configurados en el perfil y intenta enviar 
un cobro manual, mostrar aviso:
"Para incluir datos de transferencia en 
tus cobros, configura tu cuenta bancaria 
en Perfil → Datos bancarios"
